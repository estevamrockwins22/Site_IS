# Identidade Subestimada — Site Oficial

Site oficial da **Identidade Subestimada**, banda de Rock Alternativo / Grunge.

O projeto reúne a página pública da banda e um painel administrativo para gerenciamento de conteúdo, utilizando **HTML, CSS e JavaScript** no frontend, **Node.js + Express** no backend e **Supabase** como banco de dados e autenticação.

## 🌐 Site

O frontend publicado atualmente está disponível em:

https://estevamrockwins22.github.io/Site_IS/IS/frontend

## 🎸 Sobre o projeto

O site foi desenvolvido para apresentar a identidade da banda, sua história, integrantes, lançamentos, galeria, agenda de shows, avisos, redes sociais e formas de contato.

Entre os principais recursos estão:

* História da banda
* Integrantes e funções
* Discografia e faixas
* Galeria de imagens
* Agenda de shows
* Mural de avisos
* Links para plataformas oficiais
* Área de contato
* Clipes do YouTube
* Painel administrativo protegido por autenticação

## 🛠️ Tecnologias
